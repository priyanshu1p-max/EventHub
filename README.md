# EventHub – Event Management & Ticket Booking Platform

EventHub is a full-stack web application that simplifies event discovery, management, and ticket booking. It provides separate functionality for customers, organisers, and administrators, allowing users to explore events, book tickets securely, make online payments, and manage bookings.

### Key Features
- User authentication and authorization using JWT.
- Role-based access for Customers, Organisers, and Admins.
- Event creation, management, and approval.
- Event discovery, search, and recommendations.
- Online ticket booking with Razorpay payment integration.
- QR code-based digital tickets and ticket verification.
- Booking cancellation and refund request tracking.
- Saved events and personalised recommendations.
- Organiser dashboard for managing events and bookings.

### Technology Stack
- **Frontend:** React.js, JavaScript, HTML, CSS
- **Backend:** Java, Spring Boot, Spring Data JPA, Hibernate
- **Database:** MySQL
- **Authentication:** JWT
- **Payment Gateway:** Razorpay
- **QR Code:** HTML5 QR Code
- **API Integration:** REST APIs, Axios
